# Blockchain

Interactive blockchain transaction-security portfolio prototype by Avinash Rathi.

Features:
- Demo wallet and transaction creation
- Pending transaction pool
- SHA-256 hashing
- Proof-of-work mining
- Nonce and previous-hash chaining
- Wallet balances derived from ledger history
- Insufficient-balance validation
- Chain integrity validation
- Browser-local persistence using localStorage

Open `index.html` to run the project in a browser.
